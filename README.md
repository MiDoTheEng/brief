# Brief

Share any video to Brief (YouTube, X, Instagram, Facebook, Pinterest, your gallery, any app) and get a written brief of it: Short or Detailed, in English or Arabic. Briefs are kept in the app and can be exported as PDF (saved to Downloads/Brief).

How it works: YouTube captions are used when available; otherwise the audio is sent to Groq's free Whisper to get a transcript, and a Groq model writes the brief. Needs a free Groq API key (console.groq.com/keys), added in Settings.

The APK is built by GitHub Actions on every push and published to the "latest" release.
